# Getting Started With the Reporting Tool

## Tutorial: Creating Your First Report

1. Select the New Report button located in the upper-right corner of the screen.
2. Select a template from the list of 10 available options.
3. Once you select a template, the report builder opens automatically.
4. Enter a title, then select Save. A confirmation message appears.

## How to Share a Report

There are two sharing options: Anyone with the link and Specific people only. You can configure each option separately, and the settings save automatically once you select the Share button.

We recommend double-checking the recipient list before sending, to ensure a report isn't accidentally shared with the wrong person.

## How to Troubleshoot Loading Issues

If the report fails to load correctly, clear the browser cache before contacting support.

## Reference: User Roles and Permissions

There are three user roles: Admin, Editor, and Viewer. A user's role determines what they're allowed to do. For example, an Editor can't delete reports.

## Reference: Account Setup Steps

Before the dashboard can be accessed, an administrator must complete the following steps: verify the account, grant the correct permissions, and send an email invitation.

## Explanation: Account Setup Wizard Timing

:::note
The wizard takes approximately 5 to 10 minutes to complete. Most users finish in less than 5 minutes.
:::

## Explanation: Report Deletion

Reports can't be recovered once they're deleted, so be careful when removing old reports.

## Explanation: Report Access Ownership

To ensure that every teammate has access, each user's manager should add them to the report, not IT.

## Explanation: Cause of Report Loading Failures

This is usually caused by an outdated session token.
