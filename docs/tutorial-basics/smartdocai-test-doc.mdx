# Getting Started With the Reporting Tool

The Reporting Tool helps every user manage reports more efficiently. Read this guide before you begin.

## Account Setup and Configuration

Before you can access the dashboard, an administrator must complete the following steps: verify the account, grant the correct permissions, and send an email invitation from the system.

There are three user roles: Admin, Editor, and Viewer. A user's role determines what they can do. For example, an Editor can't delete reports.

:::note
The wizard takes approximately 5 to 10 minutes to complete. However, most users finish in less than 5 minutes.
:::

## Creating Your First Report

1. Select the **New Report** button in the upper-right corner of the screen.
2. Select a template from the list of 10 available options.
3. Once you select a template, the report builder opens automatically.
4. Enter a title, then select **Save**. A confirmation message appears.

You can't recover reports once you delete them, so be careful when you remove old reports.

## Sharing and Permissions

Double-check the recipient list before you send a report, so you don't accidentally share it with the wrong person.

There are two sharing options: **Anyone with the link** and **Specific people only**. You can configure each option separately. The system saves the settings automatically once you select **Share**.

To ensure that every teammate has access, each user's manager, not IT, should add that user to the report.

## Troubleshooting

If the report fails to load correctly, clear the browser cache before you contact support. This issue is usually caused by an outdated session token.

For more assistance, see the FAQ section, or contact support.
