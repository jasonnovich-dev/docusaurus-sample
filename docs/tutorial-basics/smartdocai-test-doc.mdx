# Getting started with the reporting tool

The reporting tool helps users manage their reports more efficiently. Please read this guide before you begin, as it will be useful for anyone who is new to the platform.

## Tutorial: Creating your first report

1. Select the "New Report" button located in the upper right hand corner of the screen.
2. Select a template from the list of 10 available options.
3. Once you have selected a template, the report builder opens automatically.
4. Enter a title, then select "Save". A confirmation message appears.

## How-to: Set up and configure an account

Before an administrator can access the dashboard, the following steps must be completed: the account must be verified, the correct permissions must be granted, and the system must send an email invitation.

## How-to: Share a report

There are two sharing options: "Anyone with the link" and "Specific people only". You can configure each option separately, and the settings save automatically once you select the "Share" button.

## How-to: Troubleshoot a report that fails to load

If the report fails to load correctly, clear the browser cache before contacting support.

For more assistance, see the FAQs section, or contact our support team, who are available every day.

## Reference: User roles

There are three user roles: Admin, Editor, and Viewer. A user's role determines what they can do. For example, an Editor can't delete reports.

## Explanation: Account setup timing

:::note
The wizard takes approximately 5-10 minutes to complete. However, most users finish in less than 5.
:::

## Explanation: Report deletion

Reports can't be recovered once they're deleted, so be careful when removing old reports.

## Explanation: Sharing considerations

You don't want to accidentally share a report with the wrong person, so we recommend double-checking the recipient list before sending.

To ensure that every teammate has access, each user's manager, not IT, should add them to the report.

## Explanation: Common cause of load failures

This is usually caused by an outdated session token.
