# Getting Started With the Reporting Tool

The reporting tool helps every user manage their own reports more efficiently. Read this guide before you begin, it's useful for anyone who is new to the platform.

## Account setup and configuration

Before you can access the dashboard, an administrator must complete the following steps: verify the account, grant the correct permissions, and send an email invitation.
There are three user roles: Admin, Editor, and Viewer. A user's role determines what they can do. For example, an Editor can't delete reports.
Note: The wizard takes about 5 to 10 minutes to complete. However, most users finish in less than 5 minutes.

## Creating your first report

1. Select the **New Report** button in the upper-right corner of the screen.
2. Select a template from the list of 10 available options.
3. After you select a template, the report builder opens automatically.
4. Enter a title, then select **Save**. A confirmation message appears.

You can't recover reports once you delete them, so be careful when removing old reports.

## Sharing and permissions

To avoid accidentally sharing a report with the wrong person, double-check the recipient list before you send it.
There are two sharing options: **Anyone with the link** and **Specific people only**. You can configure each option separately, and the settings save automatically when you select **Share**.
To ensure that every teammate has access, each user's manager should add them to the report, not IT.

## Troubleshooting

If the report fails to load correctly, clear the browser cache before you contact support. An outdated session token usually causes this issue.
For further assistance, see the FAQs section, or contact our support team, who are available every day.
