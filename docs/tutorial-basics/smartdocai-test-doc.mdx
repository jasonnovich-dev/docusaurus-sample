# Getting started with the reporting tool

The reporting tool helps you manage your reports more efficiently. Please read this guide before you begin — it's useful for anyone who is new to the platform.

## Understanding user roles and permissions

There are three user roles: Admin, Editor, and Viewer. Your role determines what you're allowed to do. For example, an Editor can't delete reports.

## How to set up an account

Before you can access the dashboard, an administrator must complete the following steps: verify the account, grant the correct permissions, and send an email invitation.

:::note
The wizard takes approximately 5-10 minutes to complete. Most users finish in less than 5 minutes.
:::

## How to create your first report

1. Select **New Report** in the upper-right corner of the screen.
2. Select a template from the list of 10 available options.
3. After you select a template, the report builder opens automatically.
4. Enter a title, then select **Save**. A confirmation message appears.

:::note
Reports can't be recovered once they're deleted, so be careful when removing old reports.
:::

## How to share a report

There are two sharing options: **Anyone with the link** and **Specific people only**. You can configure each option separately, and the settings are saved automatically after you select **Share**.

To give a teammate access, that user's manager should add them to the report, not IT.

:::note
Double-check the recipient list before sending to avoid accidentally sharing a report with the wrong person.
:::

## Troubleshooting

If the report fails to load correctly, clear your browser cache before you contact support. This is usually caused by an outdated session token.

For more information, see the FAQ, or contact our support team, who are available every day.
