# Getting Started With the Reporting Tool

The reporting tool helps every user manage their own reports more efficiently. Read this guide before you begin, since it's useful for anyone who is new to the platform.

## Account setup and configuration

Before you can access the dashboard, an administrator must complete the following steps: verify the account, grant the correct permissions, and send an email invitation.

There are three user roles: Admin, Editor, and Viewer. A user's role determines what they're allowed to do. For example, an Editor can't delete reports.

Note: The wizard takes approximately 5-10 minutes to complete. However, most users finish in less than 5 minutes.

## Creating your first report

1. Select the **New Report** button located in the upper-right corner of the screen.
2. Select a template from the list of 10 available options.
3. After you select a template, the report builder opens automatically.
4. Enter a title, then select **Save**. You should see a confirmation message appear.

Reports can't be recovered once you delete them, so be careful when removing old reports.

## Sharing and Permissions

You don't want to accidentally share a report with the wrong person, so we recommend double-checking the recipient list before sending.

There are two sharing options: **Anyone with the link** and **Specific people only**. You can configure each option separately, and the app saves the settings automatically once you select **Share**.

To ensure that every teammate has access, each user's manager, not IT, should add that user to the report.

## Troubleshooting

If the report fails to load correctly, clear the browser cache before contacting support. An outdated session token usually causes this issue.

For more help, see the FAQ section, or contact our support team, who are available every day.
