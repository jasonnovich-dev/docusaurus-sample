# Getting started with the reporting tool

The reporting tool was designed to help every user manage their reports more efficiently.

## Tutorial: Creating your first report

1. Select **New Report** in the upper right corner of the screen.
2. Select a template from the list of 10 available options.
3. Once you select a template, the report builder opens automatically.
4. Enter a title, then select **Save**. A confirmation message appears.

## How to set up and configure an account

Before the dashboard can be accessed, an administrator must complete the following steps: verify the account, grant the correct permissions, and send an email invitation.

## How to share a report

There are two sharing options: **Anyone with the link** and **Specific people only**. You can configure each option separately, and the settings save automatically once you select **Share**.

## How to troubleshoot a report that fails to load

If the report fails to load correctly, clear the browser cache before contacting support.

For more information, see the FAQ, or contact support, available every day.

## Reference: User roles

There are three user roles: Admin, Editor, and Viewer. A user's role determines what they're allowed to do. For example, an Editor can't delete reports.

## Explanation: Account setup timing

:::note
The wizard takes about 5-10 minutes to complete. Most users finish in less than 5 minutes.
:::

## Explanation: Report deletion

Reports can't be recovered once deleted, so be careful when removing old reports.

## Explanation: Sharing considerations

Double-check the recipient list before sending, to avoid sharing a report with the wrong person.

Each user's manager, not IT, should add that user to the report to ensure every teammate has access.

## Explanation: Troubleshooting cause

This is usually caused by an outdated session token.
