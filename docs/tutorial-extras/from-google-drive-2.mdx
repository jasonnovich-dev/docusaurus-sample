# Sharing and Permissions Reference

This page helps you manage your sharing settings more efficiently. Read this guide before you begin.

## Configuring Access Levels

Before a report can be shared, an administrator must complete the following steps: verify the recipient's account, grant the correct permissions, and send an email invitation.

There are three access levels: Viewer, Commenter, and Editor. A user's role determines what they can do. For example, a Viewer can't edit reports.

Note: Revoking access takes effect immediately. However, cached copies may remain visible to the user for up to 5 minutes.

## Revoking Access

1. Select **Manage Access** in the upper-right corner of the screen.
2. Select the user whose access you want to revoke.
3. After you select a user, the access panel opens automatically.
4. Select **Remove**. A confirmation message appears.

You can't restore revoked access automatically, so be careful when removing collaborators.
