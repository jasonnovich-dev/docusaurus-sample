# Onboarding Guide

This guide explains how to set up the widget for your team. There are
many steps, so read them carefully.

First, you need to download the installer. It's located on the downloads
page. Then, select the "Install" button, which will begin the installation.

Once it's done, the widget will be ready to use. You can then configure
it via the settings menu, where you can change many options like the
color and the size.

If you have any issues, don't hesitate to reach out. Support is happy to
help.
