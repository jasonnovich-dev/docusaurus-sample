# Onboarding Guide

## How to install the widget

1. Download the installer. It's located on the downloads page.
2. Select the "Install" button, which begins the installation.

## How to configure the widget

Once installation is done, the widget is ready to use. You can configure
it via the settings menu.

## Configuration reference

Options available in the settings menu:

- Color
- Size
