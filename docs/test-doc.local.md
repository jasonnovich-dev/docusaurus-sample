# Onboarding Guide

## Tutorial: Setting Up the Widget

This tutorial walks you through setting up the widget for your team.

1. Download the installer from the downloads page.
2. Select the "Install" button to begin the installation.
3. Wait for the installation to finish. Once it's done, the widget is ready to use.
