# Getting Started with the Reporting Tool

The Reporting Tool helps users manage reports efficiently. Read this guide before you begin. It's useful for anyone who is new to the platform.

## Account setup and configuration

Before you can access the dashboard, an administrator must complete the following steps: verify the account, grant the correct permissions, and send an email invitation.
There are three user roles: Admin, Editor, and Viewer. A user's role determines what they're allowed to do. For example, an Editor can't delete reports.
Note: The wizard takes approximately 5 to 10 minutes to complete. Most users finish in less than 5 minutes.

## Create your first report

1. Select **New Report** in the upper-right corner of the screen.
2. Select a template from the list of 10 available options.
3. Once you select a template, the report builder opens automatically.
4. Enter a title, then select **Save**. A confirmation message appears.

Reports can't be recovered once you delete them, so be careful when you remove old reports.

## Sharing and permissions

Double-check the recipient list before you send a report to avoid sharing it with the wrong person.
There are two sharing options: **Anyone with the link** and **Specific people only**. You can configure each option separately. The settings save automatically once you select **Share**.
To ensure that every teammate has access, each user's own manager, not IT, should add them to the report.

## Troubleshooting

If the report fails to load correctly, clear the browser cache before you contact support. This issue is usually caused by an outdated session token.
For further assistance, see the FAQ, or contact support, which is available every day.
